# TrackFlow UI Conventions

- Keep the public website and internal backoffice in separate folders with separate layouts and styles.
- Use visible content that reflects TrackFlow's logistics operations, warehouses, carriers, inventory, shipments, or returns.
- Build repeated public website elements as real reusable components.
- Use semantic HTML, labelled controls, keyboard-accessible interactions, visible focus states, and meaningful headings.
- Keep backend logic out of `uis/`; static sample data and browser rendering are allowed.
